========================================
🚀 快速启动
========================================

Windows:
1. 双击 install.bat 安装依赖
2. 双击 start.bat 启动服务
3. 打开浏览器访问：
   - 用户端: http://localhost:3000
   - 管理后台: http://localhost:3001

Linux/macOS:
1. chmod +x install.sh start.sh
2. ./install.sh
3. ./start.sh
4. 打开浏览器访问上述地址

手动方式:
1. npm run install:all
2. npm run dev
